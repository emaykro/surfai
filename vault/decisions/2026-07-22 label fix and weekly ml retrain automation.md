# 2026-07-22 — Восстановление обучающих лейблов + еженедельный авторетрейн

## Контекст

Аудит 2026-07-22 показал: модель v4 (обученная 2026-05-10 на 109 конверсиях) простояла без ретрейна 10 недель, при том что реальных лейблов накопилось ~800. Хуже: часть лейблов терялась системно.

## Проблема 1: потеря лейблов (~120 сессий, 15% выборки)

Два пути теряли `session_features.converted = true`:

1. **Гонка при конверсии.** Оба конверсионных пути в `server.js` (SDK goal event и `POST /api/conversions`) делали голый `UPDATE session_features`. Если конверсия приходила раньше первого `computeAndStore()` (строки фич ещё нет), UPDATE попадал в 0 строк и лейбл молча терялся. ~70 сессий (50 lead_himchistka, 9 lead_sluhnn, 5 lead_sequoia, 5 form_submit).
2. **Metrica-импорт вообще не ставил лейбл.** `metrica-import-conversions.js` вставлял конверсии, но не трогал `session_features`. Все 51 колл-трекинговый лид stefcom не участвовали в обучении — самый ценный тип конверсии.

**Фикс (коммит 21f639f):** все три пути теперь UPSERT (`INSERT ... ON CONFLICT (session_id) DO UPDATE`) — заглушка-строка с `converted=true` создаётся до расчёта фич; upsert фич в `store.js` не трогает `converted`, поэтому лейбл выживает. Backfill одним UPDATE восстановил 120 лейблов (lead_predicted исключён — предсказанные конверсии НЕ должны попадать в обучающий таргет, это самоотравление).

## Проблема 2: ручной ретрейн не выполнялся

План «еженедельный ретрейн» с 2026-05-10 не выполнялся ни разу. За это время: 3 новых сайта в cold-start, сайт 0ca60c1c градуировал без site-модели, p99 скоров упал до 0.2 при пороге predicted_lead 0.7 (генерация почти остановилась).

**Фикс (коммит 663898d):** `surfai-ml-retrain.timer` — вс 02:30 MSK, запускает `ops/ml-retrain.sh`:

```
python3 -m ml cluster --all   # рефит центроид + перелейбл всех сессий
python3 -m ml train           # глобальная + site-модели (guard регрессий внутри)
python3 -m ml score --all     # полный рескоринг
```

**Порядок критичен:** `behavior_cluster` — категориальная фича модели, а id кластеров k-means произвольны и перемешиваются при рефите. Кластеры фитятся ДО обучения, рескоринг — ПОСЛЕ, иначе модель видит фичу с чужой семантикой.

Скрипт держит 3 последних `preretrain_<stamp>.cbm` для отката глобальной модели (у site-моделей guard автоматический, у глобальной — нет; откат руками: `cp preretrain_*.cbm latest_model.cbm`).

- 6 site-моделей (было 4): добавились 0ca60c1c и 33e5615e. Рескоринг: 40 162 site-routed / 243 global.
